# أرشيفنا | Arsheefna Community

نسخة عامة من كود تطبيق أرشفة الوثائق على Windows للمراجعة البرمجية وتقديم الملاحظات.

**تنبيه:** هذا مستودع للمراجعة وليس إصداراً جاهزاً للاستخدام الإنتاجي. لا تستخدم بيانات أو وثائق حقيقية في التجارب. ميزة مشاركة الشبكة في نسخة المصدر الحالية تستخدم HTTP عند تفعيلها، لذلك لا تشغّلها مع معلومات حساسة.

## التشغيل محلياً

يتطلب Node.js وpnpm على Windows:

```powershell
pnpm install --frozen-lockfile
pnpm start
```

ملفات أيقونات Windows الثنائية غير مضمنة في هذه النسخة الأولية؛ بناء المثبّت عبر `pnpm dist` يتطلب توفير أيقونات خاصة بك في `build/icon.ico` و`build/icon.png`.

## المراجعة

نرحب بتقارير الأخطاء واقتراحات التحسين عبر Issues، مع ذكر خطوات إعادة الإنتاج والملف والسطر. لا تنشر كلمات مرور أو وثائق أو مفاتيح في Issue عام. للمشكلات الأمنية الحساسة استخدم قناة تواصل خاصة مع مالك المستودع.

## الحقوق

لم يُحدَّد ترخيص مفتوح المصدر بعد. نشر الكود للقراءة والمراجعة لا يمنح تلقائياً حقوق إعادة استخدامه أو توزيعه.
